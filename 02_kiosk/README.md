# ☕ Python Cafe Kiosk

Python 기초 문법과 객체지향 프로그래밍을 활용하여 구현한
**콘솔 기반 카페 키오스크 토이 프로젝트**입니다.

## 주요 기능

* 카페 메뉴 조회
* 메뉴 및 수량 선택
* 장바구니 추가 / 조회 / 초기화
* 총 주문 금액 계산
* 주문 결제 및 취소
* `txt` 파일을 이용한 신규 메뉴 추가

## 프로젝트 구조

```text
02_kiosk/
│
├── kiosk_main.py
├── kiosk_menu.py
├── kiosk_order.py
└── kiosk_data/
    └── menu.txt
```

## 사용한 Python 문법

* Class / Method
* Dictionary / List
* Module
* File I/O
* while 반복문
* match-case
* try-except 예외 처리

## 실행

```bash
python kiosk_main.py
```

## 프로젝트 목적

Python의 **클래스, 모듈화, 파일 입출력**을 직접 활용하여
간단한 키오스크 프로그램의 동작 흐름을 구현하는 것을 목표로 제작했습니다.
