# 🎬 영화관 좌석 예매 시스템

Python 기초 문법을 활용하여 구현한 **콘솔 기반 영화관 좌석 예매 토이 프로젝트**입니다.

좌석 예매, 취소, 예약 현황 조회 기능을 구현했으며
영화관 좌석을 **2차원 리스트**로 관리했습니다.

---

## 좌석 구성

좌석은 **A~F행, 1~20번**으로 구성되어 있으며 총 **120석**입니다.

```text
A1 ~ A20
B1 ~ B20
C1 ~ C20
D1 ~ D20
E1 ~ E20
F1 ~ F20
```

예약된 좌석은 별도의 리스트로 관리합니다.

```python
reserved_seat = []
```

---

## 주요 기능

### 1. 좌석 예매

원하는 좌석 번호를 입력하여 예약할 수 있습니다.

```text
예약할 좌석을 입력하세요 : a10

A10 좌석 : 예약 성공!
```

입력값은 `strip()`과 `upper()`를 이용하여 공백과 대소문자를 처리합니다.

이미 예약된 좌석은 중복 예약할 수 없습니다.

---

### 2. 좌석 예약 취소

예약된 좌석을 입력하면 예약을 취소할 수 있습니다.

```text
예약 취소할 좌석을 입력해주세요 : A10

A10 취소 완료!
```

예약되어 있지 않은 좌석을 입력하면 예약 여부를 다시 확인합니다.

---

### 3. 좌석 현황 조회

전체 좌석의 예약 상태를 콘솔에서 확인할 수 있습니다.

```text
                     SCREEN
-------------------------------------------------

A □ □ □ □ □ □ □ □ □ □    □ ■ □ □ □ □ □ □ □ □
B □ □ □ □ □ □ □ □ □ □    □ □ □ □ □ □ □ □ □ □
C □ □ □ □ □ □ □ □ □ □    □ □ □ □ □ □ □ □ □ □
D □ □ □ □ □ □ □ □ □ □    □ □ □ □ □ □ □ □ □ □
E □ □ □ □ □ □ □ □ □ □    □ □ □ □ □ □ □ □ □ □
F ■ □ □ □ □ □ □ □ □ □    □ □ □ □ □ □ □ □ □ □
```

```text
□ : 예약 가능
■ : 예약 완료
```

10번과 11번 좌석 사이에는 통로를 표현했습니다.

## 프로그램 실행

프로그램을 실행하면 다음 메뉴가 출력됩니다.

```text
영화관 좌석 예매 시스템에 오신 것을 환영합니다!

1. 좌석 예매
2. 좌석 취소
3. 좌석 현황
4. 프로그램 종료

>>
```

메뉴 선택은 `match-case`문을 사용했습니다.

잘못된 입력은 `try-except`를 이용하여 처리하여 프로그램이 비정상 종료되지 않도록 구현했습니다.

## 학습한 내용

### 2차원 리스트 활용

영화관 좌석을 행과 열 구조로 표현했습니다.

```python
seats[i][j]
```

### 리스트를 이용한 예약 관리

```python
reserved_seat.append(seat_num)
reserved_seat.remove(seat_num)
```

예약과 취소 과정에서 하나의 리스트를 계속 수정하여 예약 상태를 관리했습니다.

### 함수 모듈화

예약, 취소, 조회 기능을 별도의 함수와 파일로 분리하면서
코드의 역할을 나누고 가독성을 높이는 방법을 연습했습니다.
