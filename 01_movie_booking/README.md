    # 01. Movie Booking System

Python 기초 문법을 활용하여 구현하는 간단한 영화관 예매 시스템입니다.

영화 조회, 좌석 선택, 예매 및 취소 기능을 구현하면서  
함수, 자료구조, 예외 처리, 파일 입출력, 모듈화 등을 연습하는 것을 목표로 합니다.

---

## 주요 기능

- 영화 목록 조회
- 영화 선택
- 좌석 현황 조회
- 좌석 선택
- 영화 예매
- 예매 내역 확인
- 예매 취소
- 잘못된 입력에 대한 예외 처리

---

## 학습 목표

이번 프로젝트를 통해 다음 내용을 연습합니다.

- 함수 정의 및 호출
- `if`, `for`, `while`을 활용한 프로그램 흐름 제어
- 리스트와 딕셔너리를 활용한 데이터 관리
- `try-except`를 활용한 예외 처리
- 파일 입출력을 활용한 예매 정보 저장
- 기능별 코드 분리를 통한 모듈화
