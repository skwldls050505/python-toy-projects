# Python Toy Projects

Python 기초 문법과 프로그래밍 실력을 향상시키기 위해 진행한 토이 프로젝트 모음입니다.

작은 프로그램을 직접 구현하면서 Python 문법뿐만 아니라
프로그램 구조 설계, 예외 처리, 파일 입출력, 모듈화 등을 연습하는 것을 목표로 합니다.

---

## 학습 목표

- Python 기본 문법 복습
- 함수와 클래스 활용
- 리스트, 딕셔너리 등 자료구조 활용
- `try-except`를 이용한 예외 처리
- 파일 입출력
- 모듈화
- 프로그램 구조 설계
- Git / GitHub를 활용한 코드 관리
